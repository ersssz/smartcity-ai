# Discovery: погода и тематические даты

Проверено 20.10.2026 по первичным источникам. Реализация: новые `apps/mobile/src/discovery/context.ts` и `useDiscoveryContext.ts`; Root подключает их к карточкам. Никаких API-ключей, GPS телефона, billing или платных fallback.

## Погода

[Условия Open-Meteo](https://open-meteo.com/en/terms) разрешают Free API для некоммерческих частных/некоммерческих приложений без подписок и рекламы: менее 10 000 запросов/сутки, 5000/час, 600/мин. Это основание только для текущей частной бесплатной беты; публичная коммерциализация/реклама потребует нового решения, без автоматического включения платного доступа. Наш клиент делает не более одной попытки за 30 минут на JS process, включая неудачу/отмену, без фонового обновления или retry. Этот локальный лимит не заменяет общий лимит провайдера при большом числе установок.

[Лицензия данных](https://open-meteo.com/en/licence) — CC BY 4.0. Рядом с показом actual weather UI получает обязательную ссылку «Weather data by Open-Meteo · CC BY 4.0» на Open-Meteo. Текст/округление/погодный ranking — преобразование приложения, а не одобрение провайдера. При unknown/manual нет заимствованных показаний температуры и не создаётся видимость актуальных данных.

[API documentation](https://open-meteo.com/en/docs) описывает `current` как модельные 15-минутные условия; `timeformat=unixtime` — UTC seconds. Приложение запрашивает только фиксированную городскую точку 51.1694,71.4491, Celsius/mm/kmh/UTC, шесть current полей. Это не точная позиция пользователя и не прогноз на весь маршрут. UI показывает время модели с датой и Астана UTC+5. Проверяются единицы, число/диапазон, городская область, supported WMO subset, возраст не более90минут и будущее не более10минут; unsupported/invalid/stale не получают weather boost. Root выбрал более узкое fail-closed подмножество кодов без97, хотя текущая таблица API его описывает.

Снег/осадки/холод/ветер имеют приоритет перед солнцем. Пороги — продуктовая эвристика выбора короткой прогулки, не предупреждение метеослужбы и не обещание безопасности. При плохих условиях waterfront ниже коротких внешних осмотров. `hasIndoorOption` не означает фактически запланированное посещение внутри; `hoursVerified` также не доказывает, что сейчас открыто. Вход и часы всегда требуют проверки; текущие5 visits — outside only. Ручные sunshine/rain/cold/windy ясно помечены как выбранные пользователем, без°C.

## Календарь

[Официальная таблица gov.kz для2026](https://www.gov.kz/article/33969?lang=ru) подтверждает Новый год1–2января, Рождество7января,8марта, Наурыз21–23марта,1/7/9мая, Курбан-айт27мая2026, День столицы6июля, День Республики25октября, День Независимости16декабря. Перенесённые выходные не становятся новыми датами событий.

В таблице отсутствует День Конституции. Отдельное [актуальное сообщение государственного органа](https://www.gov.kz/org/maslihat-aksuat/press/news/details/1183356?lang=ru) подтверждает ежегодную дату15марта и вступление новой Конституции1июля. Поэтому в тематические даты добавлено15марта, а устаревшее30августа из календарей2025 не использовано. [Официальный акт Әділет](https://adilet.zan.kz/rus/docs/Z010000267_) в web reader возвращает JS-only страницу; mirror adilet.kz не выдаётся за первичный акт.

Это тематическая подборка подтверждённых дат2026, не полный юридический/производственный календарь. В2027+ функция возвращает unknown до обновления; число Курбан-айта не переносится на другой год. Date boundary считается фиксированнымUTC+5, независимо от timezone телефона. Today/upcoming ограничены7днями; речь о поводе открыть историю/архитектуру, без вымышленных фестивалей, событий и часов работы.
