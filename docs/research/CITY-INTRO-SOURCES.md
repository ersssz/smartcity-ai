# Знакомство с Астаной: основания коротких карточек

Проверка: **20 октября 2026 года**. Это редакционный материал для интерактивного знакомства, не набор границ, не навигационные маршруты и не полевая приёмка. Факты перепроверены по открытым первичным публикациям; тексты написаны своими словами. Изображение пользователя служит референсом визуальной подачи и не используется как доказательство административных границ.

## Состав города и река

В паспорте [Плана развития Астаны на 2026–2030 годы](https://www.gov.kz/org/astana/documents/details/940185?lang=ru) прямо указаны **шесть** районов: Алматы, Байконур, Есиль, Сарыарка, Нура, Сарайшык. Стабильные идентификаторы карточек: `almaty`, `baikonyr`, `esil`, `nura`, `saryarka`, `sarayshyq`. Названия на KK: Алматы, Байқоңыр, Есіл, Нұра, Сарыарқа, Сарайшық; дополнительное основание — [перечень районных мероприятий «Наурызнама-2026»](https://www.gov.kz/org/astana/press/news/details/1178711?lang=ru). Латинские варианты в EN — проектная транслитерация для интерфейса, не утверждение о единственном юридическом английском написании.

Берега относятся к **реке**, а не озеру. Природоохранное управление прямо использует двойное название [Есиль (Ишим)](https://www.gov.kz/org/sko-tabigat/press/news/details/478263?lang=ru). [Материал проекта улицы ТМ-66, раздел 1.2.2](https://www.gov.kz/uploads/2023/4/19/1bae6e198173a9ff2ce4da0b62ba0817_original.6964189.pdf) сообщает, что Астана расположена на двух берегах Ишима, и далее называет основной рекой Есиль. Этот отчёт подготовлен подрядчиком ИП «ТАБЫС» для городского транспортного управления и размещён на GOV.KZ: используем только устойчивый географический факт, не его оценки экологии и не старое административное деление. Исторические сведения о районах в старых источниках не заменяют актуальный список из плана развития.

«Левый/правый берег» и административный район — разные способы описания города. В карточках нет правила «любой объект этого района обязательно на одном берегу», координат береговых полигонов или обещания точных границ. Название Нура само по себе не означает, что город делит река Нура.

OSM координаты получены живыми ограниченными запросами Overpass по именам/ID в городской области (`out center tags`), без геокодирования личной позиции, аккаунтов и платных вызовов. `out center` для площадного объекта — центр bounding box, не точка входа и не доказательство того, что вся площадь объекта целиком находится внутри района. У OSM relation 15957444 название «Астана саябағы / Парк Астана» и центр 71.4195693, 51.1548152, который тоже попадает в Нуру; это дополнительная пространственная согласованность, но совпадение с алиасом «Центральный» не утверждается только по близости.

Воспроизведение результата без сети из корня репозитория:

```python
import hashlib, json
from pathlib import Path

path = Path('data/city-intro/districts.geojson')
assert hashlib.sha256(path.read_bytes()).hexdigest() == (
    '75bd63ec2e553cb399158bfd47e7c4ccb648d20ea2ce8591492aeb43ff98507a')
features = json.loads(path.read_text(encoding='utf-8'))['features']

def in_ring(point, ring):
    x, y = point
    inside = False
    for a, b in zip(ring, ring[1:]):
        if (a[1] > y) != (b[1] > y):
            if x < (b[0] - a[0]) * (y - a[1]) / (b[1] - a[1]) + a[0]:
                inside = not inside
    return inside

def contains(point, geometry):
    polygons = (geometry['coordinates'] if geometry['type'] == 'MultiPolygon'
                else [geometry['coordinates']])
    return any(in_ring(point, p[0]) and
               not any(in_ring(point, h) for h in p[1:]) for p in polygons)

cases = [
    ('Khan Shatyr', (71.4038726, 51.1325089), 'nura'),
    ('Central Park', (71.41902, 51.152859), 'nura'),
    ('Ataturk Park', (71.431587, 51.1521023), 'baikonyr'),
    ('Botanical Garden', (71.4165705, 51.1061652), 'esil'),
    ('Triathlon Park', (71.4497779, 51.1352766), 'almaty'),
    ('Zheruyik', (71.4899608, 51.1455747), 'almaty'),
    ('Peace Palace', (71.4634559, 51.123123), 'sarayshyq'),
    ('Hazret Sultan', (71.4721928, 51.1254256), 'sarayshyq'),
    ('National Museum', (71.4693823, 51.1182297), 'sarayshyq'),
    ('Independence Palace', (71.472049, 51.1206309), 'sarayshyq'),
]
for label, point, expected in cases:
    actual = [f['properties']['id'] for f in features
              if contains(point, f['geometry'])]
    assert actual == [expected], (label, actual, expected)
print('PASS: 10/10 landmark reference coordinates in expected OSM districts')
```

Это воспроизведение фиксирует согласованность контента с конкретной картой приложения, не законность границ, физический доступ, входы и полевую проходимость. У набережной Шабал Бейсековой и жилых кварталов по проспекту Республики источник территориальной связи — публикация городского/районного органа; отдельная координатная приёмка всей набережной/улицы не выполнена. Нуржол не представлен как объект, целиком принадлежащий одному району; карточка называет ориентир для начала знакомства, а подготовленная прогулка имеет собственные точные точки и переходы.

## Редакционная подача и ограничения

- `description` — короткая фактическая опора, не более двух предложений на язык. `tagline` — авторский заголовок. `experience` начинается явным указанием редакционного совета и предлагает способ обратить внимание на место, а не сообщает измеренный комфорт.
- Нет оценок «самый комфортный», «тихий», «безопасный», обещаний безбарьерности, защиты от ветра, открытого входа или доступности парков во всех условиях. Факт существования общественного пространства не доказывает текущую физическую проходимость.
- Это не шесть готовых прогулок. Первая подготовленная прогулка в продукте существует отдельно; карточки остальных районов не должны выдавать кнопку запуска отсутствующего маршрута.
- RU написан редакционно. Переводы KK и EN — **проектные**, человеческая языковая вычитка остаётся `pending`. Не маркировать их как профессионально отредактированные.
- JSON не содержит изображения пользователя, HTML статей и длинных цитат. Ссылки предназначены для проверки; свободная лицензия на чужие тексты/фотографии не предполагается. `verifiedAt` означает дату чтения источников, не дату обновления их исходных сведений; часть районных публикаций выпущена до 2026 года. Выше отдельно перечислены десять выполненных координатных проверок; они не заменяют сверку OSM с официальным текстом новых границ. Геометрия OSM имеет собственную атрибуцию и лицензию ODbL, описанные в `data/city-intro/metadata.json`; районные рассказы написаны своими словами.

## Отдельное предупреждение для владельца геометрии

В [первичном ИПС «Әділет»](https://old.adilet.zan.kz/rus/docs/P2600000697/history) подтверждено постановление Правительства от **4 августа 2026 года №697**: первая официальная публикация в ЭКБ — **7 августа 2026 года**. Владелец геометрии дополнительно проверил дату введения **8 августа 2026 года** в `/info` и тексте постановления; эти даты отражены в `data/city-intro/metadata.json`. Самостоятельный повторный запрос автора контента к `/info` завершился таймаутом, но `/history` с датой первой публикации открыт и прочитан. OSM-координаты остаются картографическим обзором сообщества: наличие этого постановления не подтверждает автоматическое соответствие каждого OSM-сегмента его тексту. Некоторые районные OSM relations старше постановления. Текст карточек не содержит площадей, координат границ и юридических утверждений.
