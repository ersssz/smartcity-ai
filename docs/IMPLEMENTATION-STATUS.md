Результаты заносятся после фактической проверки. Доступность MCP/подписки Codex не подтверждает бесплатный API для продукта. Секреты и точные личные координаты в отчёты не записываются.

Общий локальный runner прошёл: 25 тестов data/replay, 22 теста spend policy и один регрессионный тест mobile lifecycle, всего 48; две проверки TypeScript также прошли. Mobile-тест использует имитацию адаптеров ОС и SQLite. Точные условия записаны в [local-verification.json](../evidence/local-verification.json).

Обнаружен принципиальный разрыв T01: Expo TaskManager восстанавливает задачи до запуска JavaScript, а LocationTaskConsumer передаёт координаты в служебную очередь Android с persisted JobScheduler. Отсутствие координат в нашей SQLite и очистка из JavaScript не доказывают отсутствие фонового возобновления или хранения в ОС. Диагностика не считается соответствующей продуктовым правилам приватности. До беты нужен отдельный нативный механизм активного сопровождения и проверка его lifecycle; реальный телефон остаётся дополнительным, а не единственным условием приёмки. [Конкретный следующий ticket](T01-NATIVE-PRIVACY-FOLLOWUP.md) фиксирует нативный модуль, удаление прежнего пути, независимый от JavaScript Stop, проверку APK и отдельную проверку миграции. Это проект решения, его реализация ещё не выполнена.

Координация T02: главный Codex отправил поручение через Windows-MCP; второй Codex использовал `/root/poi_ingestion`, `/root/provider_evidence` и `/root/hours_evidence`. Финальный исследовательский результат закреплён на `0ea6f8f93bef07e7a16406143eecd7d069411989`, доставлен Git bundle и независимо проверен на главном ноутбуке в отдельной копии. Полный T02 не принят: принят ограниченный результат исследования, описанный в [REPORT](../evidence/t02/REPORT.md).

Проверки нулевых расходов: отдельный локальный модуль policy запрещает неизвестного/платного провайдера по умолчанию, проверяет свежесть доказательства бесплатности, конечную квоту и ограничения запроса. Он не выполняет сетевые запросы, не подтверждает сам подлинность доказательства и не резервирует квоту. Реальные генераторы/RAG пока выключены; наличие тестов не заменяет проверку условий бесплатного сервиса.

Данные T02: второй ноутбук получил публичный Geofabrik Kazakhstan PBF (224566151 bytes, SHA-256 `9ad8e895d4703248b97a5d17e883e49dc58549305aa4ba6bd6661d247cb98bdb`). На главном ноутбуке Overpass вернул HTTP 502; дополнительный запрос прекращён после получения статуса Geofabrik. Успешного Overpass extract на главном ноутбуке нет, TLS-проверка не отключалась.
