Результаты заносятся после фактической проверки. Доступность MCP/подписки Codex не подтверждает бесплатный API для продукта. Секреты и точные личные координаты в отчёты не записываются.

Общий локальный runner повторён: 25 тестов data/replay, 22 теста spend policy и 10 регрессионных тестов mobile lifecycle; отдельно 7 JVM-проверок разрешения сеанса, всего 64. Две проверки TypeScript также прошли. ОС/SQLite и время в этих тестах имитируются. Условия: [native-local-verification.json](../evidence/t01/native-local-verification.json). Предыдущие 48 проверок сохранены в историческом [local-verification.json](../evidence/local-verification.json).

Разрыв прежней диагностики устранён в новом пути сбора: вместо восстановления Expo TaskManager и persisted JobScheduler используется process-bound LocationManager listener, одноразовое разрешение Start в памяти и независимый от JS/SQLite native Stop. Через асинхронные события передаётся только сигнал; актуальная точка читается из памяти при открытом экране. Старые классы и компоненты исключены из проверенного APK. [Исходный ticket и границы](T01-NATIVE-PRIVACY-FOLLOWUP.md), [независимый review](../evidence/t01/native-review.md), [APK](../evidence/t01/native-location-apk.json), [попытка установки](../evidence/t01/android12-device-check.json). Это не доказывает очистку исторических Expo payloads, работу при stalled JS на телефоне, Android 14+, батарею или полевую надёжность — эти gates остаются открытыми.

Координация T02: главный Codex отправил поручение через Windows-MCP; второй Codex использовал `/root/poi_ingestion`, `/root/provider_evidence` и `/root/hours_evidence`. Финальный исследовательский результат закреплён на `0ea6f8f93bef07e7a16406143eecd7d069411989`, доставлен Git bundle и независимо проверен на главном ноутбуке в отдельной копии. Полный T02 не принят: принят ограниченный результат исследования, описанный в [REPORT](../evidence/t02/REPORT.md).

Проверки нулевых расходов: отдельный локальный модуль policy запрещает неизвестного/платного провайдера по умолчанию, проверяет свежесть доказательства бесплатности, конечную квоту и ограничения запроса. Он не выполняет сетевые запросы, не подтверждает сам подлинность доказательства и не резервирует квоту. Реальные генераторы/RAG пока выключены; наличие тестов не заменяет проверку условий бесплатного сервиса.
