# Локальный прогресс и управляемая публикация без аккаунта

Для первой версии пользователь выбрал отсутствие входа и восстановления, но обновляемую публичную коллекцию. Локальная история остаётся на устройстве; сервер получает выбранную публикацию, а отдельный секрет устройства даёт управление ею. Срок 30 дней и возможность отзыва уменьшают длительность доступности забытой публикации, но не дают восстановления при потере устройства; точные правила находятся в DECISIONS.md A05.
