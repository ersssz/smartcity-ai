# Текущая прогулка исполняется на телефоне

Потеря сети и недоступность генерации не должны уничтожать уже начатую прогулку. Сервер готовит версионированный WalkBundle, а мобильный модуль владеет выполнением и локальным прогрессом. Это увеличивает ответственность локального хранения и обновления формата, зато прохождение не зависит от постоянного агентного цикла на сервере; новый онлайн-план применяется как явное обновление пакета с сохранением выполненных действий.
