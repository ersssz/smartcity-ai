## Что получает пользователь

Прогулка содержит связанную историю, наблюдательное задание и открытие в локальной коллекции; первое GPS-прибытие и ручное выполнение отображаются честно.

## Scope и самостоятельность

WalkSession Quest/Chapter, Achievement и Collection. Факты поступают через factRefs; редакционная полнота контролируется T14.

Исполнитель самостоятельно выбирает Implementation внутри согласованного Interface. Нормативные сущности и численные пороги берёт из PRODUCT-SPEC/GLOSSARY/ARCHITECTURE/DECISIONS. Изменения общих Interface, миграций, зависимостей/lockfile и нового обещания пользователю согласует с владельцем. Другие модули не рефакторит попутно.

## Критерии приёмки

- [ ] В промежуточном первом районе работает связанная сюжетная цепочка с наблюдательными заданиями без требования платного входа/опасных действий. Полный содержательный минимум M2 из PRODUCT-SPEC принимается в T17.
- [ ] Задания, подсказки, результат и связанные открытия доступны RU/KK/EN и работают из сохранённого пакета.
- [ ] Условия открытия явно различают Arrival и ManualVisitMark/ручной ответ; достижение описывает именно то, что приложение подтвердило.
- [ ] Повтор события/ответа, перезапуск и повторное завершение не создают дубли главы, значка или открытия.
- [ ] Фактическая история имеет источники; художественная рамка обозначена. Неизвестный факт не становится правильным ответом квеста.
- [ ] Коллекция локальна по умолчанию; призов, денежной ценности, античит-обещаний и лидербордов в первой бете нет.
- [ ] После завершения показана следующая подходящая глава/прогулка с понятным учётом уже открытого; при отсутствии новой подтверждённой главы это явно сообщается. Минимальная повторная ценность US-36/37 входит в M2, улучшение после пилота — T20.

## Ошибки и пограничные случаи

- Контент главы несовместим с bundle revision: сохранить ранее открытое и запросить согласованное обновление.
- Задание невозможно на месте: разрешить пропуск с понятной пометкой, не блокировать безопасное завершение прогулки.

## Доказательство готовности

- Видео открытия главы → задание → итог → коллекция на трёх языках.
- Тесты повторных событий и различения GPS/ручных отметок.
- Редакционная таблица factRefs и условий каждого открытия.
