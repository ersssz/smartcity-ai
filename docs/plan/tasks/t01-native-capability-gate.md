# T01: На реальном Android проверить основу прогулки

**Владелец:** Root  
**Blocked by:** Нет — может стартовать при запуске фазы разработки  
**Статус:** ready-for-agent  
**Этап:** G0 — технические gates, дни 1–5  
**Спецификация:** [PRODUCT-SPEC](../PRODUCT-SPEC.md) — US-11, US-20, US-24–25; AT-06, AT-07, AT-13–14, AT-19.  
**Решения:** [DECISIONS](../DECISIONS.md), [GLOSSARY](../GLOSSARY.md), [ARCHITECTURE](../ARCHITECTURE.md); численные нормы берутся из этих источников.  
**Оценка:** 1–2 рабочих дня; измеренный прогноз уточняется после baseline.  
**Base SHA / ветка:** назначает Root при старте; ветка codex/t01-native-capability-gate. Сейчас кода/репозитория нет.

## Что получает пользователь

Получить устанавливаемую диагностическую сборку, в которой пользователь видит карту и свою позицию, слышит короткий материал и продолжает активную прогулку с погашенным экраном. Это техническая проверка выбранного стека, а не готовое приложение.

## Scope и самостоятельность

Native foundation. Единственный владелец зависимостей и lockfile — Root. Expo development build + MapLibre + SQLite; Expo Go не является доказательством готовности нативных функций.

Исполнитель самостоятельно выбирает Implementation внутри согласованного Interface. Нормативные сущности и численные пороги берёт из PRODUCT-SPEC/GLOSSARY/ARCHITECTURE/DECISIONS. Изменения общих Interface, миграций, зависимостей/lockfile и нового обещания пользователю согласует с владельцем. Другие модули не рефакторит попутно.

## Критерии приёмки

- [ ] На каждом доступном тестовом Android установлена сборка; воспроизводимы development APK и подписанный standalone APK без Metro, зафиксированы модель, версия Android, версия приложения и способ сборки. Если доступен только один телефон, совместимость заявляется только для него; полная матрица технического gate из ARCHITECTURE проверяется до M2-TECH.
- [ ] Карта выбранного района, маркер позиции и маршрут отображаются; источник карты и его атрибуция видны. Проверена техническая возможность открыть разрешённый offline map package.
- [ ] Первичный тест активной прогулки длится 30 минут, из них не менее 20 минут с погашенным экраном: видимо foreground-уведомление, есть последовательность координат/состояний и явная кнопка остановки. Частота, точность, пропуски и расход батареи записаны, а не угаданы. Расширенная матрица location/audio gate из ARCHITECTURE завершается вместе с T07 до M2-TECH; короткий baseline не заменяет её.
- [ ] Проверены отказ геолокации, приблизительная геолокация, отключение GPS, ограничения батареи и остановка приложения системой; пользователь видит фактическое состояние сопровождения.
- [ ] Короткий тестовый материал RU/KK/EN воспроизводится после отключения сети. Для каждого языка зафиксирован реальный источник аудио и право сохранить его; наличие голоса в системе не предполагается.
- [ ] SQLite сохраняет и восстанавливает тестовый прогресс после выгрузки процесса. Решение G0-native имеет исход PASS/FAIL и список ограничений; FAIL не маскируется переносом требований.

## Ошибки и пограничные случаи

- Недоступная нативная библиотека или несовместимая сборка: измерить и выбрать один работающий Adapter, затем обновить решение стека.
- Нет доступного и разрешённого KK-аудио либо offline-карты: gate остаётся закрытым; текстовый режим не выдаётся за выполнение аудио/offline-обещания.

## Доказательство готовности

- APK, SHA-256 и инструкция воспроизведения установки.
- Запись экрана и обезличенный журнал 30-минутного теста, таблица устройств и батареи.
- Результат G0-native с выбранными версиями и фактическими ограничениями.

## Условия принятия

Все AC выполнены на зафиксированном SHA; независимые Standards и Spec review не имеют блокирующих замечаний; выполняется общий Definition of Done из TEAM-WORKFLOW. Сценарий/fixture/симуляция/реальная полевая проверка обозначены отдельно. Пропущенный тест или недоступный человек/устройство не объявляются PASS. Текущий файл — план, ни один checkbox не означает уже выполненную работу.
