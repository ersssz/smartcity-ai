## Что получает пользователь

На одном районе Астаны воспроизвести небольшой реальный каталог и выполнимые пешие связи; определить законный способ сформировать offline-пакет и доступную схему backend без новых расходов.

## Scope и самостоятельность

Исследовательский вертикальный spike: источник → нормализованная карточка/путь → читаемый проверочный отчёт. Не меняет нативные зависимости и общий контракт.

Исполнитель самостоятельно выбирает Implementation внутри согласованного Interface. Нормативные сущности и численные пороги берёт из PRODUCT-SPEC/GLOSSARY/ARCHITECTURE/DECISIONS. Изменения общих Interface, миграций, зависимостей/lockfile и нового обещания пользователю согласует с владельцем. Другие модули не рефакторит попутно.

## Критерии приёмки

- [ ] Автоматизированно получены минимум 15–20 реальных POI выбранного района; сохранены идентификаторы, координаты, происхождение, время получения, лицензия и результат удаления дублей.
- [ ] Для каждого критического поля различаются известное, неизвестное, устаревшее и конфликтующее. Минимум один конфликт расписания разобран с приоритетом источника и сезонным правилом.
- [ ] Контрольный набор пеших пар из ARCHITECTURE проходит настоящий foot-профиль: направление, наружные anchors/входы, переход через дорогу/реку, барьеры и правдоподобность длины. Автомобильный маршрут и прямая линия не засчитываются; техническая геометрия не выдаётся за полевую проходимость.
- [ ] Отдельно доказана законная техническая маршрутизация от реальной текущей GPS-точки пользователя и к выбранному реальному концу, включая возврат к фактическому старту. Проверены условия провайдера, передача этих данных, достаточная геометрия подхода/возврата и допустимый расход. Согласие пользователя на геолокацию само по себе не отменяет ограничения провайдера.
- [ ] Политика публичных anchors у ORS, если используется этот Adapter, не подменяет GPS start/end: выбор публичного anchor возможен только как явно согласованное изменение старта/конца, с честно показанным ограничением. Прямая линия, вымышленный connector и «как будто пользователь уже у anchor» не закрывают разрыв пути. Если провайдер не допускает реальный GPS-запрос, проверяется законный альтернативный Adapter; без решения gate маршрутизации и M2-TECH остаются закрыты.
- [ ] Выбран разрешённый способ получить offline-подложку района; размер, время упаковки, атрибуция и условия распространения измерены. Массовая загрузка tile.openstreetmap.org не используется.
- [ ] Подтверждены доступность выбранных аккаунтов/кредитов, backend Workers + Supabase, лимиты и условия; ключи не попадают в доказательства. Платные API выключены до проверки разрешённого остатка, без подключения новых платежей.
- [ ] Проверка RAG из ARCHITECTURE выполнена настоящим generator на фактах, полученных из импортированных карточек: сохранены модель/API ID, разрешённый режим, обезличенные запросы/ответы, ошибки, качество и измеренные задержки по трём языкам. Доступный ключ или шаблонный текст эту проверку не заменяет; end-to-end время probe и latency генератора отмечены раздельно.
- [ ] В таблице G0-data есть PASS/FAIL по данным, пешему пути, offline-правам, RAG и расходам. Фактическое покрытие ограничено проверенным районом; доступность всего города не объявляется доказанной.

## Ошибки и пограничные случаи

- Timeout публичного сервиса: сохранить ошибку, применить ограниченные повторы и законный локальный импорт/кэш; не выдавать отсутствие ответа за отсутствие POI.
- Нет устойчивого backend при $0: указать доступные часы/ограничения закрытого пилота и оставить gate публичной непрерывной работы закрытым.
- Реальная GPS-точка вне разрешённого anchor/графа, невозможен подход к старту или возврат: честный отказ/явное предложение изменить старт; маршрут не выдаётся как полный. Отсутствие законного live-routing не обходится через публичный proxy или скрытую замену координат.

## Доказательство готовности

- Воспроизводимая команда импорта, checksum исходных данных и очищенная выборка 15–20 карточек.
- Таблица нормативного набора пеших пар с фактическими результатами и источниками; отдельно — обезличенные live GPS start/end/return кейсы и правовое основание выбранного Adapter. Точные личные координаты не публикуются в артефактах.
- Реестр лицензий/лимитов/доступности и решение G0-data без секретов.
