## Что получает пользователь

Пользователь может удалить локальные данные, отозвать публикацию и продолжить сохранённую прогулку при исчерпании внешних ресурсов; APK не раскрывает серверные ключи.

## Scope и самостоятельность

Вертикальные privacy/cost сценарии Android → Workers → Supabase/PublicCollection. Не является общим бесконечным аудитом.

Исполнитель самостоятельно выбирает Implementation внутри согласованного Interface. Нормативные сущности и численные пороги берёт из PRODUCT-SPEC/GLOSSARY/ARCHITECTURE/DECISIONS. Изменения общих Interface, миграций, зависимостей/lockfile и нового обещания пользователю согласует с владельцем. Другие модули не рефакторит попутно.

## Критерии приёмки

- [ ] В production APK, репозитории, собранных assets и очищенных logs нет OpenAI/Google/backend-admin ключей и device admin capability других пользователей.
- [ ] Права backend и таблиц минимальны; чужие публикации и закрытые данные не читаются/изменяются через подмену id или token.
- [ ] Передача геолокации минимизирована по действию, включено объяснение разрешений; точные GPS-треки не отправляются в публичный профиль или обычную аналитику.
- [ ] Удаление локальной истории/пакетов/прогресса имеет явный объём и подтверждение; отзыв публикации выполняется отдельно и его статус честно показан.
- [ ] Есть жёсткие серверные лимиты запроса/токенов/частоты и отключение внешнего AI при исчерпании разрешённой квоты. Платёжные обязательства не подключаются автоматически.
- [ ] При quota/error пользователь сохраняет доступ к загруженным материалам и прогрессу; dashboard/отчёт различает реальный расход, оценку и неизвестный остаток.

## Ошибки и пограничные случаи

- Удаление offline при публикации online: не обещать немедленный отзыв до подтверждения сервера, показать ожидающую операцию.
- Недоступен учёт лимита: fail-closed для платного вызова, а не бесконтрольный повтор.

## Доказательство готовности

- Secret scan APK/репозитория и негативные backend-тесты.
- Видео delete/revoke/quota сценариев.
- Карта минимальных данных, retention и фактические лимиты без секретов.
