# T02 research data

These files are a bounded research interchange format, not the shared Android/backend contract. Integration remains owned by Root. See [the T02 report](../../evidence/t02/REPORT.md) for gate status and reproduction.

OSM-derived POIs, public node references and path geometry: **© OpenStreetMap contributors**, [ODbL 1.0 and attribution](https://www.openstreetmap.org/copyright). Preserve source IDs, hashes, acquisition timestamps, attribution and applicable database share-alike obligations. Names in a language exist only when sourced; missing translations are unknown.

An OSM point/building center is not a verified entrance. Raw `opening_hours` is not a parsed, confirmed schedule. Mapped paths do not prove today's accessibility, permissions, crossings or winter conditions. Public-node geometry does not prove a path from an actual GPS position.

`bayterek-hours-observations.json` is a separate set of minimal attributed factual observations from the venue and official tourism publications. Their narratives/images/HTML are not redistributed and no general open licence is asserted for those sites. The summer closing-rule disagreement is retained; current opening is unknown.

Large public PBF and intermediate exports stay in ignored `raw-data/`. No model key, personal endpoint or private track is included.
