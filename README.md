# AstanaAI

Android-продукт для цельных прогулок по Астане. Разработка ведётся на двух ноутбуках с субагентами и независимой проверкой. Актуальный [статус](docs/IMPLEMENTATION-STATUS.md); согласованный [план](docs/plan/README.md) сохранён как основание.

Текущая вертикаль — [«Город между небом и землёй»](docs/FIRST-EDITORIAL-WALK.md): публичный старт у Байтерека, Нуржол, Круглая площадь и возвращение к старту. Включает пешую геометрию из OSM, три главы RU/KK/EN, вопросы с подсказками, ручные отметки, локальную коллекцию, повторное чтение и SQLite-прогресс. Выбранная редакция пакета сохраняется вместе с сеансом. После перезапуска приложение открывает паузу; GPS запускается отдельным действием.

Это подготовленная прогулка. Серверный WalkBundle, генерация по запросу, RAG, адаптация маршрута, публичные профили, подготовленный звук и полноценные офлайн-карты ещё не приняты. Полевое прохождение и человеческая редактура KK/EN остаются открытыми. Наличие system TTS не доказывает его офлайн-работу.

- [Android](apps/mobile/README.md): интерфейс прогулки и отдельная техническая диагностика нативного GPS.
- [Редакционный контент и источники](content/first-walk/content-draft.json), [перепроверка источников](evidence/first-walk/content-source-recheck.md).
- [Данные T02](evidence/t02/REPORT.md): 20 карточек и ограниченный воспроизводимый OSM replay; это не готовый управляемый routing/RAG-сервис.
- [Политика расходов](packages/spend-policy/README.md): неизвестные и платные провайдеры запрещены по умолчанию. Реальные модельные API выключены. Покупки, платные API и облачная сборка запрещены даже при наличии ключа или средств.

Из корня, с уже установленными зависимостями mobile:

```powershell
.\scripts\verify-local.ps1 -PythonPath 'C:\Path\To\python.exe'
```

Runner ничего не скачивает и не устанавливает: data/replay, spend policy, TypeScript, жизненный цикл, прохождение глав, реальные SQLite-транзакции, приоритетный Stop, фактический каталог и синтетические отказные проверки builder. Проверки SQLite выполняются Node, не Android. Отдельные JVM-проверки описаны в mobile README. Результаты и границы доказательств находятся в `evidence`.

Предыдущий APK 0.1.1 ограниченно проверен на Xiaomi Android 12: запуск и реальные provider callbacks, сервис в течение 81 секунды Dozing, Stop из уведомления, сохранение ручного счётчика после перезапуска уже остановленной сессии. Это не доказательство прохождения новой прогулки, точности в поле, полного фонового сбора, гибели активного процесса, длительной батареи, Android 14+ или очистки старых Expo payloads. [Подробности](evidence/t01/android12-runtime-20261020.json).
