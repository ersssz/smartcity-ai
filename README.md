# AstanaAI

Рабочий репозиторий Android-продукта для цельных персональных прогулок по Астане.

Разработка начата 20 октября 2026 по прямому поручению пользователя. Исходный согласованный [план](docs/plan/README.md) сохранён как версия основания; актуальный прогресс находится в [IMPLEMENTATION-STATUS](docs/IMPLEMENTATION-STATUS.md).

Первая параллельная работа: T01 — мобильная диагностическая сборка на главном ноутбуке, T02 — реальные открытые данные и пешая маршрутизация на ноутбуке друга. Телефон сегодня недоступен, поэтому проверки настоящего Android/GPS остаются предстоящими. Наличие каркаса не закрывает их.

Все исполнители работают без покупок, включения billing, платных API и платных cloud builds. Обязательные правила — [AGENTS.md](AGENTS.md).
