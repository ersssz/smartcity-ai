# AstanaAI

Исходный код и план Android-продукта для цельных персональных прогулок по Астане.

Разработка начата 20 октября 2026 по прямому поручению пользователя. Исходный согласованный [план](docs/plan/README.md) сохранён как версия основания; актуальный прогресс находится в [IMPLEMENTATION-STATUS](docs/IMPLEMENTATION-STATUS.md).

Реализация идёт параллельно на двух ноутбуках, в отдельных Git-ветках, с независимым ревью перед объединением. На сегодня:

- [План продукта](docs/plan/README.md): спецификация, архитектура, решения, распределение работы и 22 задачи.
- [Android T01](apps/mobile/README.md): собран отдельный диагностический APK со встроенным JavaScript, без необходимости Metro; MapLibre, явные Start/Pause/Stop, диагностический прогресс SQLite и проверка голосов RU/KK/EN. Подпись и состав APK проверены. Запуск на устройстве и устранение обнаруженных рисков приватности ещё впереди — [T01-EVIDENCE](apps/mobile/T01-EVIDENCE.md).
- [Данные T02](evidence/t02/REPORT.md): 20 реальных карточек района Байтерека, происхождение и лицензия; шесть технических пеших путей и четыре корректных отказа на OSM-данных. Replay сохраняет 145 исходных записей. Исследовательский результат принят и объединён; полная приёмка T02 остаётся открытой.
- [Политика расходов](packages/spend-policy/README.md): локальный запрет неизвестных и платных провайдеров, ограничение квоты/токенов, 22 теста. Реальные API не включены.

Общая локальная проверка прошла: **48 тестов** (25 data/replay + 22 policy + 1 mobile lifecycle), а также две проверки TypeScript. Тест mobile использует имитацию адаптеров ОС; replay использует записанные публичные геоданные. Это отдельные виды доказательств.

Из корня репозитория, после установки зависимостей mobile по его README:

```powershell
.\scripts\verify-local.ps1 -PythonPath 'C:\Path\To\python.exe'
```

Команда запускает доступные локальные проверки без загрузок, учётных данных, сетевых API и установки приложения на телефон.

Открыты проверки физического Android/GPS и батареи, нативного восстановления геолокации, полного offline-пакета и аудио, подходов от реальной позиции, доступности бесплатного backend и настоящего RAG. Телефон сегодня недоступен по решению пользователя. M2-TECH и полевая готовность пока не приняты; актуальные границы — в [IMPLEMENTATION-STATUS](docs/IMPLEMENTATION-STATUS.md).

Все исполнители работают без покупок, включения billing, платных API и платных cloud builds. Обязательные правила — [AGENTS.md](AGENTS.md).
